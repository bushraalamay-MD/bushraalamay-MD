## Boshra Alamari Adabo, MBChB

Physician working where clinical medicine, public health research and health data meet.

I design studies, build monitoring and evaluation frameworks, and turn health data into evidence that decision-makers can act on.

### What I work on

- **Epidemiology & surveillance**: outbreak response, reporting completeness and timeliness, trend analysis
- **Program evaluation**: quasi-experimental designs (difference-in-differences, interrupted time series), KAP surveys
- **Monitoring, Evaluation & Learning (MEL)**: indicator frameworks, logic models, performance evaluation
- **Health data workflows**: digital data collection with KoboToolbox, cleaning and analysis in R and Python
